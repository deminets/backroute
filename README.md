# Backroute

**Backroute** — это специализированный модуль расширения для подсистемы NetFilter/iptables в операционной системе Linux, предназначенный для реализации механизма принудительной обратной маршрутизации (back routing) на канальном уровне.

## Описание и принцип работы

В стандартном сетевом стеке Linux ответные пакеты направляются на основе глобальной таблицы маршрутизации ядра. Модуль `backroute` изменяет этот принцип: он интегрируется в структуру отслеживания соединений (`conntrack`), сохраняя информацию о сетевом интерфейсе и MAC-адресе источника входящего соединения. 

При формировании ответного пакета модуль принудительно отправляет его через сохраненный сетевой интерфейс на MAC-адрес отправителя, полностью игнорируя стандартную таблицу маршрутизации ядра.

## Области применения

Модуль является эффективной альтернативой связке технологий `CONNMARK` и политики маршрутизации (policy routing). Ключевые сценарии использования включают:
*   Серверы с несколькими публичными IP-адресами.
*   Конфигурации с несколькими шлюзами (MultiWAN), через которые различные клиенты устанавливают входящие соединения.
*   Ситуации, когда использование сложных правил маршрутизации на основе меток пакетов нецелесообразно или технически затруднено.

## Ограничения

*   Поддерживаются только **tap** (Ethernet) устройства.
*   Работа с **tun** устройствами на текущий момент не поддерживается.

## Установка и сборка

Проект реализован на языке C и использует стандартный `Makefile`. Для сборки модуля ядра необходимо убедиться, что в системе установлены заголовочные файлы ядра Linux (kernel-headers / kernel-devel).

```bash
# Сборка модуля
make

# Установка модуля в систему
sudo make install
```

## Пример использования

Для обеспечения корректного доступа к локальному сервису (например, SMTP-серверу на порту 25) необходимо загрузить модуль и добавить соответствующие правила в конфигурацию `iptables`.

### Базовая конфигурация

```bash
# 1. Разрешение установленных и связанных соединений (обязательное условие)
iptables -A INPUT -m state --state RELATED,ESTABLISHED -j ACCEPT

# 2. Применение модуля BACKROUTE в таблице mangle
iptables -t mangle -A PREROUTING -p tcp -m tcp --dport 25 -j BACKROUTE --update no --hookout pre
```

### Параметры модуля

При создании правила доступны следующие аргументы конфигурации:

#### `--update [no|yes]`
Определяет стратегию обновления записей в `conntrack`:
*   `no` — зафиксировать MAC-адрес и интерфейс только для первого пакета, инициировавшего прохождение через данное правило (рекомендуется для стабильных соединений).
*   `yes` — динамически обновлять MAC-адрес для всех последующих пакетов, поступающих с того же направления.

#### `--hookout [pre|post]`
Определяет цепочку NetFilter, в которой происходит перехват исходящих пакетов:
*   `pre` (PREROUTING) — перехват и отправка пакетов до прохождения стандартной маршрутизации. Данный режим критически важен при отсутствии маршрута по умолчанию (default gateway), так как предотвращает попадание пакетов в "черную дыру" (blackhole). 
    *   *Примечание:* При использовании режима `pre` такие правила, как `MASQUERADE` и `SNAT`, могут функционировать некорректно, поскольку пакеты покидают стек до применения трансляции сетевых адресов.
*   `post` (POSTROUTING) — перехват и отправка пакетов после прохождения всех стандартных этапов маршрутизации и трансляции адресов.
