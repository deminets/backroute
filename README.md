# backroute - NetFilter/iptables back route module

Возможна поддержка MultiWan для tap(ethernet)-устройств, tun-устройства пока не поддерживаются.

# Как это работает

Модуль расширения NetFilter/iptables, запоминает в структуре conntrack, устройство и MAC источника соединения, и отправляет обратные пакеты на устройство и MAC отправителя, игнорируя таблицу маршрутизации.
Можно использовать как замену технологии "CONNMARK & policy routing", для случаев наличия двух и более публичных IP-адресов у сервера, и/или наличия нескольких шлюзов, через которые клиенты могут устанавливать соединения.

# Пример использования

Если требуется обеспечить доступ к локальному SMTP-серверу, необходимо загрузить модуль и добавить следующее правило:
```
iptables -A INPUT -m state --state RELATED,ESTABLISHED -j ACCEPT
iptables -t mangle -A PREROUTING -p tcp -m tcp --dport 25 -j BACKROUTE --update no --hookout pre
Где:
update = no/yes
no - зафиксировать MAC только для первого пакета прошедшего через правило.
yes - обновлять MAC для всех пакетов, пришедших с того же направления.
hookout pre/post
pre  - перехватывать и отправлять пакеты из цепочки PREROUTING. Полезно, при отсутствии default маршрута, так как в этом случае пакеты попадают в blackhole. Но при этом не будут работать некоторые правила, например: MASQUERADE, SNAT.
post - перехватывать и отправлять пакеты из цепочки POSTROUTING.
```
